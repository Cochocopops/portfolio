🎮 RYTHME CAR GAME - Guide de démarrage rapide

═══════════════════════════════════════════════════════════

📋 PRÉREQUIS

- Python 3.7 ou supérieur
- pip (gestionnaire de paquets Python)

═══════════════════════════════════════════════════════════

🚀 INSTALLATION (3 étapes)

1. Télécharge ces 3 fichiers depuis le site :
   ✅ menu.py
   ✅ game.py
   ✅ requirements.txt

2. Ouvre un terminal dans le dossier de téléchargement

3. Installe les dépendances :
   
   pip install -r requirements.txt

═══════════════════════════════════════════════════════════

🎮 LANCER LE JEU

Dans le terminal, tape :

   python menu.py

Le jeu se lance automatiquement !

═══════════════════════════════════════════════════════════

🎯 COMMENT JOUER

- Utilise les FLÈCHES pour diriger ta voiture
- Évite les obstacles
- Synchronise-toi avec la musique pour un max de points !
- Essaie de battre ton meilleur score

═══════════════════════════════════════════════════════════

📁 FICHIERS DU JEU

menu.py          → Menu principal et sélection de difficulté
game.py          → Logique du jeu
requirements.txt → Dépendances Python
data/            → Ressources (images, audio)
scores.csv       → Sauvegarde des scores

═══════════════════════════════════════════════════════════

🛠️ DÉPANNAGE

❌ "ModuleNotFoundError: No module named 'pygame'"
   → Lance : pip install pygame

❌ "Python n'est pas reconnu..."
   → Installe Python depuis python.org

❌ Le jeu ne se lance pas
   → Vérifie que tous les fichiers sont dans le même dossier
